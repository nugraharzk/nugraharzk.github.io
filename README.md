# Rizki Nugraha's Portfolio

A modern portfolio website built with React, TypeScript, Vite, and Tailwind CSS.

## Getting Started

This project uses [Bun](https://bun.sh/) as the package manager. Make sure you have Bun installed on your system.

### Installation

```bash
bun install
```

### Development

```bash
bun run dev
```

### Build

```bash
bun run build
```

### Preview

```bash
bun run preview
```

### Deploy

```bash
bun run deploy
```

## Technologies Used

- React 19
- TypeScript
- Vite
- Tailwind CSS
- React Icons
- Bun (Package Manager)

## Template Info

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react/README.md) uses [Babel](https://babeljs.io/) for Fast Refresh
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react-swc) uses [SWC](https://swc.rs/) for Fast Refresh
